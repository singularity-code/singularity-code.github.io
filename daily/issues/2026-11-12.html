Moonshot AI, 2.8T 파라미터 오픈 웨이트 Kimi K3.1 Pro 공개

Moonshot AI가 총 2.8T, 토큰당 활성 104B 파라미터의 MoE 모델 Kimi K3.1 Pro의 가중치를 Hugging Face에 올렸다. 성능 수치는 모두 개발사 자체 보고다.

Hugging Face 모델 카드에 따르면 이 모델은 전문가 896개 중 토큰마다 16개와 공유 전문가 2개를 쓰는 MoE 구조이며, 텍스트와 이미지를 입력받고 컨텍스트는 약 100만 토큰이다. 가중치는 MXFP4, 활성값은 MXFP8로 양자화 인식 학습을 거쳤다고 적혀 있다. 라이선스는 별도의 "Kimi K3.1 Pro License"이며, 집계 자료는 대형 제품에 Kimi 이름 표기를 요구한다고 전한다(라이선스 원문은 미확인).

모델 카드의 벤치마크는 Terminal-Bench 4.0 65.7, DeepSWE v1.1 75.5, BrowseComp 92.1, GPQA-Diamond 94.2 등이다. 비교 대상은 Claude Fable 5.1, GPT-6 Astra, Claude Opus 5.5 등이고, 집계 자료에 따르면 Terminal-Bench 4.0에서 Opus 5.5는 66.4로 Kimi가 근소하게 낮다. 모두 reasoning effort "max" 설정의 자체 결과이며 독립 검증은 아직 확인하지 못했다.

API 가격은 집계 자료 기준 입력 100만 토큰당 $4, 출력 $20이다. 공개 날짜는 모델 카드에 없고 집계 자료가 11월 5일로 분류했으므로 날짜는 2차 자료 기준이다. 11월 10일자 제11호에서는 다루지 않은 소식이다.

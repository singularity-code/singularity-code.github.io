앤트로픽, 과학자 20만 세션 분석: Claude는 데이터 분석과 글쓰기에 몰린다

앤트로픽이 연구자의 Claude 사용 방식을 분석한 보고서를 11월 5일 공개했다. 컴퓨터과학 등 형식과학에 사용이 쏠리고, 자료 수집과 가설 생성은 덜 쓰인다고 한다.

보고서는 8월 2일부터 9월 30일까지의 연구 세션 207,049건을 대상으로 한다. Claude(채팅·코워크) 128,914건, Claude Code 78,135건이며, 분류기로 과제와 분야를 라벨링해 집계만 분석했다고 한다. 과학자 528명 설문도 함께 썼는데, 대부분 생명·보건과학 분야이고 앤트로픽 AI for Science 지원자라는 점은 표본의 한계다.

컴퓨터과학은 전 세계 연구자의 4.3%인데 Claude 세션의 11.9%, Claude Code 세션의 32.7%를 차지했다. 데이터 분석은 Claude 세션의 33.7%, Claude Code 세션의 48.1%로 연구자 시간 비중(27.6%)을 웃돌았다. 반대로 자료 수집은 11.5%로, 연구자 시간의 28.6%에 크게 못 미쳤다.

현재 역량만으로 AI가 연구자 시간의 27~52%(중앙값 38%)를 맡으면 연구 산출이 약 1.35~2.02배가 된다는 시나리오도 제시한다. 설문 응답자의 약 40%는 2030년까지 AI가 연구 프로젝트 전체를 자율 수행하리라 예상했다. 이는 앤트로픽의 자체 분석과 예시 시나리오이며 독립 검증은 확인하지 못했다.

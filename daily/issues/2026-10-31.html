오픈 웨이트 모델의 10월: 미스트랄이 1조 파라미터 ‘Large 4’ 가중치를 풀었다

DeepSeek, Kimi, Qwen, MiniMax가 잇따라 새 모델을 낸 달에, 유럽의 미스트랄이 29일 자사 최대 모델을 내려받을 수 있게 했다. 직접 호스팅할 수 있는 에이전트용 모델의 선택지가 빠르게 넓어지고 있다.

미스트랄 AI는 10월 29일 Mistral Large 4의 가중치를 Hugging Face에 공개했다. 10월 6일 프리뷰를 낸 지 3주 만이다. 1조 파라미터 전문가 혼합(MoE) 모델로, 토큰당 활성 파라미터는 약 520억 개, 네이티브 멀티모달이며 컨텍스트 창은 100만 토큰이다. 공식 체크포인트는 FP8과 NVFP4로 나왔고, llama.cpp와 Unsloth의 GGUF 양자화 버전도 첫날부터 올라왔다.

미스트랄에 따르면 프리뷰 기간에도 강화학습을 이어 터미널 작업 벤치마크 Terminal-Bench 4.0 점수를 28.3%에서 41%로 끌어올렸고 출력 토큰은 30% 줄였다. 이 수치는 아직 독립적으로 검증되지 않았다. 라이선스는 수정된 MIT로, 사용·수정·파인튜닝·상용화가 자유롭지만 모델을 서비스로 제공하는 사업자는 별도 상용 라이선스가 필요하다. API 가격은 100만 토큰당 입력 0.70달러, 출력 2.10달러다.

같은 달 중국 랩들의 출시도 줄을 이었다. deepset 정리로는 7월 말 이후 9개 랩이 새 오픈 웨이트 모델을 냈다. 에이전트 코딩에서는 GLM-5.3과 Kimi K3가 앞서고, 엔비디아의 Nemotron 3.5 Bolt는 24GB GPU 한 장을 겨냥한다. 로컬 실행 도구 Ollama는 10월 23일 0.40.10을 냈다.

TIOBE 10월: 파이썬 반등, 줄리아 3년 만에 복귀

10월 12일 발표된 지수에서 파이썬은 17.76%에서 19.23%로 올라 1위를 지켰다. 상위 5개 언어의 순서는 그대로였고, 10위권에서는 R이 SQL을 추월한 것이 유일한 변화다. Java는 C++와의 격차를 좁혔고 Rust는 10위를 유지했다. Julia는 0.88%로 18위에 올라 20위권에 3년 만에 돌아왔다.

이번 달부터 TIOBE가 중국어 검색어를 반영하도록 집계 방식을 바꿨다. 순위 변동의 일부는 방법론 변화일 수 있다.

TypeScript 7과 Next.js 16.4

7월 8일 정식 출시된 TypeScript 7.0은 컴파일러와 언어 서비스를 Go로 다시 썼다. Microsoft는 전체 빌드가 보통 8~12배 빨라진다고 밝혔고, VS Code 코드베이스 타입 검사는 125.7초에서 10.6초로 줄었다. 안정적인 프로그래밍 API는 7.1에서 나올 예정이라 그 전에는 호환 패키지를 쓴다. 엄격 모드가 기본으로 켜지는 등 기본값이 바뀌어 tsconfig 정리가 필요하다.

Next.js는 10월 7일 16.4.0을 안정판으로 냈다. 15.5 계열은 TypeScript 7이 JS 컴파일러 API를 제공하지 않는 탓에, 7 이상이 설치되면 알기 쉬운 오류를 내며 멈추도록 바뀌었다. 15.5 프로젝트는 TypeScript 6에 머물거나 Next.js를 올려야 한다.

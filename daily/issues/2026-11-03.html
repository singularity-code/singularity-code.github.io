앤트로픽, Agent Skills 표준을 Linux Foundation 산하 Agentic AI Foundation에 기부

에이전트에 전문 지식과 작업 절차를 주는 오픈 표준 Agent Skills의 관리가 앤트로픽에서 재단으로 넘어간다. 10월 22일 발표이며, 이전 호에서는 다루지 않았다.

앤트로픽에 따르면 스킬은 SKILL.md 파일과 보조 스크립트·참고 자료를 담은 폴더로, Claude Code를 만들며 나온 개념이다. 2025년 10월 선보였고 12월에 오픈 표준으로 공개했다. 이번에 표준 자체와 이름·로고, GitHub 조직, agentskills.io 도메인이 재단으로 이전된다.

앤트로픽은 ChatGPT, Cursor, GitHub Copilot, VS Code 등 70개 넘는 에이전트 플랫폼이 도입했고 공개 스킬이 100만 개, 설치가 약 2억 8천만 건이라고 밝혔다. 이 수치는 앤트로픽 자체 집계이며 독립 검증은 확인하지 못했다. 유지보수는 앤트로픽·Google·OpenAI 등의 엔지니어가 개인 자격으로 맡고, 버전 릴리스·제안 절차·보안 지침을 담은 로드맵은 제안 단계다. 이전 시점은 글에 명시되지 않았다.

이번 조사에서 어제 이후 새로 공개된 주요 모델은 확인하지 못했다. 오른쪽 목록은 출시 추적 사이트의 최신 항목이다.

앤트로픽, 에이전트 스킬 표준을 Linux Foundation 산하 재단에 기증

에이전트에게 전문 지식과 작업 절차를 쥐여 주는 ‘Agent Skills’ 표준이 특정 회사의 손을 떠나 Agentic AI Foundation으로 넘어갔다. 이번 주 GitHub 인기 목록 상위가 스킬 저장소로 채워진 것과 맞물리는 소식이다.

앤트로픽은 10월 22일 Agent Skills를 Agentic AI Foundation에 기증한다고 밝혔다. 이 재단은 Linux Foundation 산하다. 기증 대상에는 표준 자체뿐 아니라 Agent Skills라는 이름과 로고, GitHub 조직, agentskills.io 도메인이 포함된다.

앤트로픽은 표준이 앞으로도 열려 있고 특정 업체에 종속되지 않을 것이며, 여러 회사의 엔지니어가 개인 자격으로 유지·관리한다고 설명했다. 이는 앤트로픽 자신의 발표 내용이며, 이후 거버넌스가 실제로 어떻게 운영되는지는 아직 확인할 수 없다.

어제 호에서 다룬 오픈 웨이트 모델 출시 이후 새로 공개된 주요 모델은 아직 확인하지 못했다. 오른쪽 목록은 모델 출시 추적 사이트 기준 최신 항목이다.
